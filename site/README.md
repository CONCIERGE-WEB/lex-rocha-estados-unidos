# Direitos do Consumidor — Portugal (`lex-rocha-pt`)

Site público: **https://www.direitosconsumidor.com** (DNS → Vercel).

Marca em pt-PT; pesquisa jurídica documental. Repositório separado do mercado brasileiro.

## Desenvolvimento

```powershell
cd lex-rocha-pt
npm install
npm run dev
```

Abrir http://localhost:3010

## Build

```powershell
npm run build
```

Ver `../DEPLOY_PT.md` para Vercel e Supabase EU.
